# static-website-press-
This project demonstrates how to host a static website using cloud object storage (AWS S3 or Google Cloud Storage) and make it publicly accessible without using any traditional web server like EC2 or Compute Engine
# Static Website on AWS S3 - Portfolio

## 🚀 Live Website

**🔗 [http://shiv-portfolio-2026.s3-website.ap-south-1.amazonaws.com](http://shiv-portfolio-2026.s3-website.ap-south-1.amazonaws.com)**

## Project Goal
- Create an S3 bucket
- Enable static website hosting
- Upload HTML/CSS/JS files
- Set public bucket policy
- Access the website via public URL

## Features
- Serverless static hosting
- Zero server management
- Low cost
- Fast global access (via AWS Edge Locations)
